# Это 5 лабораторная работа. Её выполнили Матасова Аксинья и Татанова Милана. Мы создали чат-бота и настраиваем для него максимально безопасный процесс разработки(CI/CD). Это значит, что любой код, который попадает в репозиторий, автоматически проверяется на уязвимости.

Что внутри:

- pp/: Здесь сам код бота, написанный на Flask. Бот может отвечать на вопросы о бюджетах и кредитах, но он категорически не позволяет переводить деньги, выполнять код или раскрывать секретную информацию.
- 	ests/: Тут находятся тесты. Есть обычные тесты, чтобы всё работало как надо, и специальные AI-security тесты, которые пытаются "взломать" бота с помощью специально составленных запросов.
- security/semgrep/: В этой папке лежат наши правила для поиска опасного кода.
- .github/workflows/: Здесь находится скрипт, который запускает множество сканеров каждый раз, когда код обновляется.
- eports/: Отчёты о проверках собираются здесь.

Как запустить у себя:

Нужен Python 3.12.

1. Создайте виртуальное окружение и активируйте его:
   python -m venv venv
   env\Scripts\activate
2. Установите нужные библиотеки:
   pip install -r requirements.txt
3. Проверьте, что тесты проходят успешно:
   pytest -v
4. Запустите бота:
   python run.py

Что проверяет наш пайплайн безопасности:

Когда вы делаете git push, GitHub Actions автоматически запускает:
1. **pytest**: Проверяет, что ничего не сломалось.
2. **Bandit**: Ищет типичные уязвимости в Python-коде, например, использование eval() или os.system().
3. **Semgrep**: Проверяет код по нашим собственным правилам.
4. **pip-audit**: Сравнивает версии используемых библиотек с базой данных известных уязвимостей.
5. **Trivy**: Сканирует готовый Docker-образ на наличие уязвимостей в системных компонентах.

Важное примечание про ИИ:

В этой лабораторной работе чат-бот использует поддельную (mock) версию движка:
- Вам не нужно указывать настоящие API-ключи от OpenAI в репозитории.
- Мы можем целенаправленно тестировать защиту от промпт-инжектора (например, LLM01, LLM07 и другие) на уровне приложения.
